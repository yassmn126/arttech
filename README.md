# genesis — дневник атмосферы

Текст о дне + фото + песня → живая страница дневника (анимированная открытка 4:5 с музыкой и озвучкой),
которая сохраняется в папку дня с придуманным названием и попадает в архив.

## Запуск

```
npm start
```
Откройте http://localhost:5173. Нужен Node.js 20+, npm-зависимостей нет.
Интернет нужен для шрифтов Google Fonts, Three.js (CDN jsdelivr, версия 0.170.0) и поиска песен в iTunes.
Без сети всё работает дальше: 3D заменяется плоскими дисками, шрифты — системными, а недоступный поиск даёт понятную ошибку и не роняет сервер.

```
node server.js --archive demo-archive --port 5174   # отдельный архив, например для демо или тестов
npm test                                             # проверка правил визуальной системы
```

`npm test` прогоняет шесть дней-архетипов (каждый обязан получить свою технику), повторяемость стиля и названия из примеров кейса.

## Интерфейс

Кинематографичная ночь: тёмное матовое стекло, хром и свет.
- **Фон** — глубокое, мягко размытое свечение. Его цвета берутся из палитры выбранного дня, а сзади едва проступает размытое фото дня. Всё плавно перетекает при смене дня. Сверху — блики «из окна», редкие звёзды и плёночное зерно.
- **Стекло.** Навигация, панель дня, ящики, карточки статистики и окна записи сделаны из тёмного матового стекла: `backdrop-filter`, тонкая светящаяся кромка, мягкое внутреннее свечение.
- **Главные кнопки** («Новый день», активная вкладка, ▶, «Скачать открытку») светятся акцентным цветом дня.
- **Движение.** Кнопки приподнимаются при наведении и вдавливаются при нажатии. С `prefers-reduced-motion` движение отключено.
- **Шрифты:** Prata — логотип-«genesis» со звёздочкой и заголовки, Manrope — интерфейс, Caveat — рукописная заметка. На карточке воспоминания остаются Fraunces, Caveat и JetBrains Mono, на стикерах — Nunito.

Главный экран:

- **Слева — архив в коробках от CD на тонкой линии времени.**
  - Тёмные jewel-case с обложкой дня, хромовым корешком и бликом, плюс дата, название и BPM.
  - Список плывёт по вертикали в духе XMB: колесо, ↑ ↓, PgUp/PgDn, Home/End, перетаскивание, стрелки ▲▼.
  - Центральный день лежит на светящейся карточке из матового стекла, на него указывает светящаяся точка.
  - Когда список останавливается, диск этого дня меняется в плеере, а адрес становится `#/day/<id>`.
- **В центре — 3D CD-плеер** (Three.js) из тёмного шлифованного металла.
  - Хромированный корпус, графитовая панель со шлифовкой, дымчатая прозрачная крышка на хромовой петле с гравировкой «genesis».
  - Отражения берутся из собственной «ночной студии»: тёмная комната с несколькими полосами софтбоксов. Хром ловит свет, а панель остаётся глубокой.
  - Радужный диск с постером дня падает внутрь и крутится один оборот за такт (240 / BPM секунд), на паузе плавно останавливается. Поверх — неподвижные радужные блики, как на настоящем CD.
  - Вокруг диска — шкала с бегущей светящейся дугой прогресса. Клик по шкале перематывает песню.
  - Серебряная рифлёная ручка «ЗВУК» и светящиеся кнопки ⏮ ▶ ⏭ и ↻ («Случайный день»). Снизу светятся полосы цвета настроения.
  - Клик по диску открывает открытку дня.
  - Всё нажимается мышью. Для клавиатуры и экранных дикторов есть те же кнопки в HTML, а без WebGL они становятся видимой панелью с плоским диском.
- **Справа — панель дня из матового стекла:**
  - Дата и название (Prata).
  - Звуковая дорожка дня: силуэт свой у каждого дня, до места проигрывания подсвечен, во время музыки дышит в такт. Клик — перемотка.
  - BPM и бейдж настроения. Пять рожиц, отдельная «напряжённо» для напряжённых дней.
  - Погода с иконкой. Берётся только из текста записи: дождь/снег/солнце…, иначе сезон и время суток. Геолокация не используется.
  - «Моя заметка» — первая фраза записи от руки.
  - Наклонённая карточка дня со скрепкой: это постер в выбранном стиле фото, клик открывает «Открытку дня».
  - Вкладки дня:
    - ♫ «Песня» — источник и встроенный плеер для ссылок.
    - ★ «Почему?» — почему такой стиль.
    - ♥ «Открытка» — живая карточка 4:5 с музыкой.
    - 🪐 «Случайный» — случайный день.
    - ✎ «Запись» — текст, озвучка и кнопка «Перерисовать по текущим правилам» (`POST /api/days/<id>/restyle`; текст, фото, песня, название и папка не меняются).
  - Под панелью — кнопки «Новый день» и «Архив» (фокус на списке).

**Стили фото на открытке.** Стиль выбирается при записи дня (над предпросмотром) и меняется в «Открытке дня». Он сохраняется в `entry.json` как `frame`, а `memory.jpg` перерисовывается под него (`POST /api/days/<id>/frame`). Обложка в архиве и печать на диске тоже обновляются.

- **Арт-постер** (по умолчанию) — авторская карточка 4:5 одной из шести техник.
- **Полароид** — классическая белая рамка, а у ярких живых дней — пастельная в цвет настроения. Широкое поле внизу с рукописным названием и датой, лёгкий наклон, второй снимок под первым.
- **Фотобудка** — вертикальная лента из четырёх кадров в цвет настроения, со штампом даты. Если фото меньше четырёх, они повторяются с разным кадрированием. Вспышка бежит по кадрам в такт песне.
- **Плёнка 35мм** — тёмная плёнка с перфорацией и надпечаткой по краю. Кадр стоит, а потом протягивается, раз в «слот» ритма. Есть оранжевый штамп даты 'ГГ ММ ДД, заметное зерно и наклейка-этикетка с названием.
- **Скрапбук** — снимки с рваными бумажными краями, приклеенные полупрозрачной васи-лентой в цвет дня, записка с названием, звёздочки и сердечки.

Рамка — это подача, а атмосфера остаётся от анализа дня. Фото внутри рамки обработаны техникой дня (мазки Моне, ноктюрн, Ротко…), цвета рамки, ленты и стикеров берутся из палитры, слайд-шоу и вспышки идут по BPM.
Для дней-«Кандинских» в рамке используется мягкий дуотон, а слишком тёмные снимки чуть высветляются, чтобы фото читалось.
Внизу каждой рамки — общая для серии строка: № дня, песня, BPM и название стиля.

«Скачать открытку» сохраняет спокойный кадр текущего стиля (JPG 1080×1350): без вспышки и покачивания, с тем же расчётом времени, что и `memory.jpg`.

**Стикеры на открытке (по желанию).** По умолчанию открытка чистая. Под ней в «Открытке дня» есть лоток из семи оригинальных Y2K-стикеров:
- хром-звезда;
- искорки (в видео мерцают);
- полупрозрачная васи-лента в цвет дня;
- марка с палитрой дня;
- штемпель с датой;
- минидиск;
- кассета с подписанным от руки названием.

Можно добавить до трёх и перетащить мышью прямо по открытке; «×» убирает. Стикеры сохраняются в `entry.json` как `stickers` (`POST /api/days/<id>/stickers`; сервер проверяет их той же функцией `cleanStickers`, что и браузер). Они рисуются поверх готового отпечатка — значит, есть в `memory.jpg`, в «Скачать открытку», на диске в плеере и в MP4.

**Капсула времени.** Кнопка «✦ Капсула времени» в шапке (и вкладка 🪐) переносит к случайному другому дню. На главном экране список плавно доезжает с маленькой вспышкой «капсула времени», и день сразу начинает играть. С других экранов она открывает день с `?play`.

**Статистика / Vibe Wrapped** (`#/stats`) — мини-отчёт по сохранённым дням:
- «Твоя палитра» — палитры последних 12 дней по порядку (клик открывает день) и лента их цветов;
- средний темп с разбросом;
- главное настроение («напряжённо» считается отдельно) и типичный вайб — самое частое слово тепла и энергии;
- любимая техника и подписанные полоски по всем шести;
- любимый стиль фото, чаще всего звучащий исполнитель, сколько собрано видео.

Считает чистая функция `computeStats` (проверена в `npm test`).

**Видео воспоминания (шаг 2).** В «Открытке дня» кнопка «Видео» собирает MP4 1080×1350 (H.264 + AAC, или VP9/Opus, если браузер не умеет H.264/AAC).
Видео получается в текущем стиле фото, длиной 12–30 с (целые такты, примерно два прохода по фото), и сохраняется в папку дня как `memory.mp4`.

- **Как собирается.** Кадр за кадром через WebCodecs (библиотека Mediabunny с CDN), а не записью экрана. Поэтому быстрее реального времени, точно в долю и работает даже в фоновой вкладке. Визуальные пульсации и вспышки фотобудки идут по громкости звука, который реально лежит в файле.
- **Какой звук попадает в файл** (правило авторских прав):
  - **Свой файл** (права подтверждены при записи) — его фрагмент до 30 с.
  - **Песня из поиска iTunes или ссылка** — песня в файл **не** встраивается: официальный фрагмент можно только слушать в приложении, а у ссылок аудио нет вовсе. Вместо неё звучит оригинальная **подложка дня**, синтезированная из анализа песни (`soundtrack.js`):
    - тот же BPM;
    - мажор или минор — от настроения песни;
    - тональность — от цвета дня;
    - бочка, хэты и арпеджио — от энергии;
    - потрескивание винила — от ностальгии;
    - яркость фильтра — от звонкости песни.

  Строка с песней остаётся в самой открытке. Правила подложки проверяет `npm test`.
- **Где лежит.** В `entry.json` записывается `video`: длительность, тип звука, стиль, кодеки. Ссылки «▶ смотреть» и «⬇ скачать» появляются рядом с кнопкой.
- **Клавиши:** ↑ ↓ — дни, пробел/Enter — играть, ← → — перемотка, + − — громкость, Esc — закрыть.
- **Новый день:** две тетрадные страницы на ленте, «запись» и «предпросмотр».

**Яркость воспоминаний:**
- Насыщенность палитры не опускается ниже порога (у тихих техник он ниже).
- Серые цвета берут оттенок самого фото, бумага — светящаяся пастель (или глубокая цветная ночь).
- Очень светлым фото добавляется немного контраста и цвета.
- Светлые страницы получают мягкий «свет из окна» вместо серой виньетки.

## Как это работает

1. **Новый день** → текст, 1–8 фото, песня (поиск / ссылка / свой файл) → «Собрать воспоминание».
2. Анализ идёт в браузере: `analyze-text.js` (настроение, сезон, время суток, места, люди → название),
   `analyze-photo.js` (палитра k-means, свет, контраст, насыщенность, теплота), `analyze-music.js` (темп, энергия, яркость, жанр, эпоха).
3. `style-engine.js` сводит три сигнала в один стиль и записывает причину каждого решения (панель «Почему этот день выглядит так»).
4. `renderer.js` и `techniques.js` рисуют страницу на Canvas: ритм идёт от BPM, а пульс берётся из живого аудиоанализатора.
5. «Сохранить» создаёт папку `archive/<дата> — <Название>/`:

```
entry.json   текст, анализ, стиль (день всегда перерисовывается одинаково)
entry.txt    название, дата, текст
photos/      01.jpg …
song.json    метаданные песни (без аудио)
song-clip.wav  только для своего файла: фрагмент ≤30 с, моно 22 кГц
memory.jpg   постер дня для ленты архива
```

## Визуальная система

**Постоянное (серия):** страница 4:5, поля 6%, сетка 12 колонок. Сверху дата и № дня (моно), фото всегда в «окне» с тонкой рамкой,
снизу слева подпись и название (Fraunces), футер с песней и техникой, фактура бумаги.

**Переменное (день):**

| Вход | Что меняет |
|---|---|
| Палитра и свет фото | основные цвета страницы, оттенок бумаги. Если цветов мало, добавляются оттенки того же цвета, а не выдуманные |
| Теплота (фото + сезон + жанр) | сдвиг палитры к охре или к сине-серому |
| Настроение и энергия текста | вес шрифта 300–900, курсив, разрядка, подпись от руки или моно |
| Темп песни (BPM) | время кадра = 4/8/12 долей; пульс на сильную долю |
| Энергия песни | амплитуда движения, склейки или растворения |
| Эпоха песни (год оригинала), ночь, ностальгия | зерно, ореол, виньетка: на любой технике |
| Минорная / медленная песня | больше воздуха, приглушённые цвета |

**Художественные приёмы:** выбираются по баллам, а не случайно. Случайность засеяна текстом дня, поэтому один и тот же день выглядит одинаково.

| Техника | Референс | Когда включается | Почему передаёт ощущение |
|---|---|---|---|
| Импрессия | мазки и свет Моне | светлый, спокойный, тёплый день, природа, вода | мазки растворяют детали, остаются свет и тепло |
| Конструкция | Кандинский, конструктивизм | напряжение, дедлайн, электроника, быстрый темп | жёсткая сетка, линии и круги, склейки в долю |
| Ноктюрн | плёночная фотография | ночь, темнота, мало света (ностальгия только подталкивает) | зерно и ореол дают налёт времени |
| Ма | японская минималистичная графика | безмятежный тихий день, очень короткая запись (<12 слов), одно фото; грусть уводит от Ма | пустота делает тишину видимой |
| Цветовое поле | Ротко | грусть, одиночество, медленная минорная музыка | крупные мягкие плоскости цвета держат тяжёлую эмоцию |
| Коллаж | вырезки Матисса | радость, много фото и людей, высокая энергия | наклонённые снимки и вырезки прыгают в ритм |

**Название:** 3–7 слов, один тон. Собирается из найденного в тексте: место, люди, предмет, сезон, погода, время суток, дедлайн.
Погода конкретнее настроения, поэтому становится прилагательным, если она есть.
Например: «Осенний парк и какао», «Ночь в офисе перед сдачей», «Вечер осенью с девушкой у пруда», «Дождливый день дома наедине с собой».

**Голос озвучки** (Web Speech API): энергия дня задаёт скорость, светлость задаёт тон. Песня приглушается под голос.

## Музыка и авторское право

- **Поиск:** iTunes Search API. Официальный 30-секундный фрагмент проигрывается и анализируется на лету через локальный прокси и **не сохраняется**.
  Год песни берётся как самый ранний среди версий той же песни того же исполнителя (iTunes датирует сборники годом переиздания). Его можно поправить вручную.
- **Ссылка** (YouTube / Spotify / Яндекс Музыка): хранятся только метаданные, при просмотре открывается встроенный плеер.
- **Свой файл:** только с подтверждением прав. Анализируется весь трек в браузере, а в папку пишется фрагмент ≤30 с.

Оценка настроения — художественный сигнал, а не психологическая диагностика.

## Инструменты

Node.js (http, fs), Canvas 2D, Web Audio API, Web Speech API, iTunes Search API, Google Fonts (Fraunces, Caveat, JetBrains Mono).
Генеративные AI-модели не используются: весь анализ и оформление построены на собственных правилах.
